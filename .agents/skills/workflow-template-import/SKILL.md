# 启动工作流程模板汇入

该技能用于通过已打开的“个人工具箱”WinUI 3 应用，将指定目录中的工作流 Excel 模板逐个预览并汇入 Aras。

## 启动输入

启动时先确认以下两项。用户已提供的信息不得重复询问：

1. **工作流命名规范**：包括前缀、主要名称的提取方式和需保留或删除的编号。
2. **汇入数据存放地址**：包含待汇入 `.xlsx` 文件的绝对目录。

如果缺少任一项，在同一个简短问题中请用户同时补充两项，不先操作应用。

## 汇入规则

- 仅处理目录直接包含的 `.xlsx` 文件，忽略 `~$` 开头的 Excel 临时文件。目录不存在或无模板时停止并说明。
- 工作流名称必须按本次用户提供的命名规范生成。先建立“文件名 → 工作流名称”映射；只有在规则无法唯一解释时才请用户确认歧义项。
- **描述始终填写源文件的完整文件名（包括 `.xlsx` 扩展名）**。
- 检查生成的工作流名称是否重复。如映射冲突，不汇入冲突文件，先请用户决定。
- 使用“覆盖”汇入模式：同名 Workflow Map 替换其节点和路径，无同名项时新增。

## 应用操作

1. 优先复用已打开的“个人工具箱”，不重复启动。如未打开，告知用户后等待其启动。
2. 进入“系统配置 → 工作流程设定”。如已在该页面，直接继续。
3. 对每个文件依次执行：填写工作流名称和描述 → “选择文件并预览” → 等待预览成功 → “确认并汇入 Aras” → 在应用确认对话框中核对名称、节点数和路径数后确认。
4. 每个文件必须看到“工作流程导入完成”结果后才记为成功并继续下一个。预览、AML 生成或汇入失败时，记录该文件错误并停止，防止后续覆盖到错误目标。
5. 完成后报告成功数、失败数以及实际使用的“工作流名称 → 描述”清单。

Windows 应用操作必须使用可用的 Computer Use 能力，不通过终端间接控制界面。
