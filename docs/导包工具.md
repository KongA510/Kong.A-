# 导包工具

入口：WinUI「系统配置 → 导包工具」，同时可从仪表盘卡片进入。旧 WPF 不增加入口。

## 使用

1. 选择当前工具箱用户保存的源连接和目标连接。两个会话独立建立，不切换全局默认 Aras 连接。
2. 选择官方 PackageImportExportUtilities 目录，点击「检查工具」。可以选择其父目录或 ConsoleUpgrade 目录。
3. 按类型和名称检索配置，勾选后可以换类型继续补选。检索最多显示 500 条；缩小关键词可继续查找。
4. 点击「分析依赖」。属性按所属对象类导出，关系类携带关系 ItemType，重复引用和循环不会反复打包。核心元数据和系统身份按前置依赖检查。
5. 「生成 AML 并比较」生成标准包并读取目标差异。依赖树显示来源和目标状态；选择差异行查看字段、关系及多语言变化。只勾选需要迁入的新增/合并项。
6. 「备份并迁入」执行前重新读取包和目标；一致后保存目标快照、新增根配置及包内已知新增 ID 清单，再用官方引擎执行 Merge / Thorough。结束后用官方导出回读验证。
7. 「执行历史」查看每次结果和备份目录。失败或取消后，先重新比较目标，再决定下一次操作。

「导出包」可另存 ZIP；「导入包」可载入官方 `.mf` 或含唯一 manifest 的 ZIP。包不会自动覆盖已有导出文件。ZIP 路径穿越、DTD、文件校验失败、无边界条件修改和删除动作均会拒绝。

源端没有 PackageDefinition 的配置也能直接选择导出。工具不会在源系统创建或修改 PackageDefinition。官方迁入会在目标建立相应 PackageDefinition、PackageGroup、PackageElement 和导入记录。

## 范围和拦截规则

支持对象类、属性、关系类、窗体、生命周期、Workflow Map 模板、共用显示配置、CUI、方法和所引用的 List、Permission、Identity、Sequence 等配置。Grid/TGV/Query Definition 等依赖以服务器实际元数据为准。

不迁移业务单据、历史审批、正在运行的流程、个人偏好、Vault 文件、服务器 DLL 或自定义图片文件。数据库 Method 内容和事件绑定保留；方法内动态名称、硬编码 ID 和外部组件需要结合依赖说明核对，自动分析不宣称能理解任意代码。

- 保留稳定 ID，版本化配置采用官方 config_id 导出方式。同名不同 ID、无法识别的引用、目标缺语言或前置包时阻断。
- 不删除目标多余配置。字段类型、数据源、多值属性变更及长度缩减阻断；需要专门的数据迁移处理。
- 一些官方导出文件包含删除自动窗体的清理段。这类文件也会阻断，不会静默删除清理段后继续导入。
- 官方拆出的多个顶层修补段保留原文及文件顺序。比较时将 Field 等修补段归入所属配置，并合并重复 ItemType 段；执行仍传递原始 AML。
- 按名称查询的 Method/Identity 引用、没有固定 data_source 的工作流路径引用会解析并验证。无法解析时保留原引用并阻断。
- 图片、样式及 HTML 中的静态同源资源执行无凭据 HEAD 检查，404/410 阻断。外部地址及无法确认的资源显示待核对提示；不上传或自动部署文件。
- 首版阻止源目标版本不同的迁移，也不支持升级或降级迁移。

## 引擎与版本

已适配官方工具 **14.0.28.41847**；JSAB 和 BLPLM 实测服务器均为 **14.0.9.36244**。只有已适配的工具 DLL 版本可以执行操作。未知版本可以检查，但不能执行迁入。

R37 已独立分发导包工具。本实现保留 `IOfficialPackageEngine` 适配接口，**尚未标记 R37 支持**；取得对应官方工具并完成兼容性测试后再添加适配器。

主程序通过独立 .NET Framework 4.8 进程加载官方工具和其配套 IOM，与主程序 R37 IOM 隔离。MD5 凭据仅通过重定向标准输入传入，不进入命令行、包和记录文件。取消在官方引擎支持的边界生效，不强杀正在迁入的进程。

构建需要 .NET 8、.NET Framework 4.8 targeting pack、现有 WinUI 依赖和合法取得的官方工具。官方 DLL 不随源码重新分发。

```powershell
dotnet build src/ArasToolkit.App.WinUI/ArasToolkit.App.WinUI.csproj `
  -p:ArasPackageEnginePath="D:/官方工具/ConsoleUpgrade"
```

本仓库默认查找与个人工具箱同级的 `PackageImportExportUtilities/ConsoleUpgrade`。部署时包含输出目录内的 `PackageBridge`，并在页面设置官方工具目录。

## 文件与恢复

运行文件保存在应用目录的 `Config/PackageMigration/<用户标识摘要>/`，不新增数据库表。

| 文件 | 用途 |
|---|---|
| `settings.json` | 连接 ID、引擎路径，不含密码 |
| `analysis-*/analysis.json` | 源端依赖和部署提示 |
| `package-*/imports.mf`、`Import/<类型>/*.xml` | 官方 manifest 与 AML |
| `package-info.json`、`checksums.json` | 来源版本、依赖说明、SHA-256 完整性 |
| `comparison-*/plan.json` | 字段/关系差异、目标快照哈希 |
| `run-*/reviewed-plan.json`、`payload/` | 已核对计划及实际执行包 |
| `run-*/backup/` | 官方目标快照、`new-items.json`、`new-owned-ids.json`、包记录备份与新增包名 |
| `run-*/after/`、`result.json` | 官方回读及逐项结果 |

新配置没有目标原始 AML，对应记录在新增清单；官方生成且未出现在源包中的内部 ID 不能由该清单穷举。包管理记录另外保存。若备份失败，迁入不会开始。

配置快照不是整库备份，也不提供整库事务回滚。恢复前应核对新增配置、已存在数据、官方包管理记录、服务器事件和其他外部副作用。本功能不提供自动反向删除或盲目重放。历史中未确认完成的执行需重新比较目标。

## 实现位置

- Core：`Models/PackageMigration`、`Interfaces/PackageMigration`。
- Services：`Services/PackageMigration`，负责独立会话、依赖、包校验、预检、备份及验证。
- `ArasToolkit.PackageBridge`：版本固定的官方适配器；不包含反编译的官方实现代码。
- WinUI：`PackageMigrationViewModel`、`PackageMigrationPage`。
- 自动回归与原生页面宿主：`tests/ArasToolkit.PackageMigration.RegressionTests`。

设计依据：[官方 Package Import/Export 文档](https://docs.aras.com/aras-innovator-platform-33/using-package-import-export-utilities/0000019f-179b-dcff-a7bf-5f9ba14c0000)、[R37 发布说明](https://docs.aras.com/aras-innovator-release-37/aras-innovator-37-release-notes)。
